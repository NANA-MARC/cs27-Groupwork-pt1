# cs27-Groupwork-pt1

Frontend simple pour un chatbox connecté à votre API IA.

## Utilisation

1. Lancez votre API (par défaut, l'interface tente d'appeler `http://localhost:8000/chat`).
2. Ouvrez `index.html` dans votre navigateur ou servez le dossier avec un petit serveur HTTP.
3. Ajustez l'URL de l'API si besoin dans le champ "URL API".

## Structure

- `index.html` : structure de l'interface.
- `styles.css` : styles du chatbox.
- `app.js` : logique d'envoi et affichage des messages.
